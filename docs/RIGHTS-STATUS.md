# 권리·출처 확인 상태 — 2026-11-18

기술 패치와 권리 허락은 별개다. 이 문서는 허락을 대신하거나 법적 결론을 내리지 않으며, 검수 자료에서 제기한 확인 항목을 기록한다. v53에서 원작의 승인·상업 출시 가능·오픈소스 허용을 새로 주장하지 않는다.

|구분|현재 근거|별도 확인이 필요한 자료|
|---|---|---|
|BanG Dream!/MyGO 인물·명칭·세계관|팬 창작으로 표시, 사용자 제공 레퍼런스와 기존 출처 문서|게임 형태의 제작·공개·배포를 포괄하는 허락과 적용 가이드라인 판본|
|타이틀 inst|사용자 제공 원본 파일, 기존 해시·크레딧 보존|게임 삽입·온라인 재배포 허락의 범위와 증빙|
|카페 재즈|기존 MUSIC-CREDITS.txt: Bossa Antigua — Kevin MacLeod, CC BY 4.0|크레딧·라이선스 링크를 유지하고 대상 파일이 같은 원본인지 확인|
|제공·기존 그림|ASSET-PROVENANCE.md 및 V51/V52 자산 문서|제공자가 원본을 가진 사실과 재배포 권한의 구별|
|생성 그림|기존 생성 이력·파일 해시 보존|원작 캐릭터를 포함한 파생 이용 권한은 별도|
|v53 WebP|image-manifest.json의 원본 경로·원본/파생 크기·SHA256|포맷 변환이 새로운 원작 이용 허락을 만들지는 않음|
|자작 코드|Git 이력과 작성 기록|저작권자의 코드 라이선스 선택. 임의의 MIT 등 라이선스는 부여하지 않음|

검수 문서의 권리 관련 지적은 해결 완료로 표시하지 않는다. 허락의 범위·지역·기간·수익화·허용 플랫폼·증빙·파생 파일을 권리자가 확인해야 한다. 원작 IP의 전면 교체나 제공 음원 삭제는 이번 안정화 패치에서 수행하지 않았다.

모든 이미지의 원본/배포 파생 경로와 해시는 `app/image-manifest.json`에서 추적할 수 있다. 출처 기록은 기존 문서를 폐기하지 않고 함께 유지한다.
