# PROJECT RiNG — 사용자 제공 걸파피코 대본 반영

2026-11-18. 사용자가 제공한 Gemini 대본 Part 1–3을 실제 런타임에 반영했다. 첨부의 인사말·후속 집필 제안은 대본에 포함하지 않았다.

- 현재 VN 110개 장면: 대사와 독립 지문 812줄. 선택 응답 6줄 포함, 기존 저장용 4개 별도 대본 포함 총 852줄.
- 영업 중 대사 82종: 처음 방문, 재방문, 품절, 대기 만료, 가격 이탈, 마감, 공연 전후, 비/창가등, 한산한 시간, 가구 설치, 첫날 정산을 원래 조건에 연결했다.
- 장면 ID/번호/제목, 기존 해금 날짜·함수, 3개 선택지의 옵션 순서·라벨·patient/rush 효과, 4개 소품의 저장 값과 효과를 유지했다. 본문과 응답은 제공 대본으로 교체했다. 줄바꿈으로 나뉜 한 문장은 연결했다.
- 식당 경영 수치·재료·보유금·장식·5개 수동 저장 슬롯·읽음·대기열은 유지한다. 새 대본의 하드코딩된 개그 수치는 경영 규칙을 바꾸지 않는다. 실제 판매 수가 나오는 짧은 대사는 실시간 수량을 사용한다.

## 저장 호환

본문 길이가 달라졌으므로 대화 contentVersion을 8로 올렸다. 이전 버전에서 읽다 멈춘 장면은 같은 장면의 새 대본 첫 줄로 이동하며, 이미 고른 선택지는 해당 새 응답으로 이어진다. 구 대화의 문장 번호를 무관한 새 문장에 대입하지 않는다. 새 버전에서 저장한 문장 번호는 그대로 복원한다. 오래된 아침 대화의 임시 세션 위치도 갱신한다.

기존 짧은/긴 대본 4종 구분은 scriptVariant로 보존한다. 백업 원본의 다른 게임 상태는 변경하지 않는다. 읽은 장면 전체를 미독으로 초기화하지 않으며, 회상에서 새 대본을 다시 볼 수 있다.

## 연출

각 대사에 맞춘 표정과 오프닝의 단계별 등장 인물을 연결했다. 독립 지문은 화자 없는 대사로 읽을 수 있다. 사용자 선호에 맞춰 커다란 의성어 효과나 폭발음을 추가하지 않았으며 오프닝 입장에는 기존 문종을 사용한다. 이전 대본의 고정 문장 번호를 대상으로 하던 감정 효과는 새 오프닝에 적용하지 않는다. 사복 CG/타이틀 이미지/inst/카페 재즈는 유지한다.

## 검증

`node work/ring-pipeline.cjs --scope all --stage`: 87개 통과.

새 `pico-script-check.cjs`는 110개 실제 등록 ID, 제공 대본의 모든 대사·지문과 4개 호환 대본, 3개 선택지 양쪽 응답/효과, 기존 해금 함수 일치, 조건부 영업 대사 82종의 실제 출력 대조, 이전 런타임 저장 110개 장면의 마지막 문장 복원, 새 저장의 문장 번호, 회상 진행 격리를 검사한다. 이전 대본의 고정 문구·문장 수를 기대하던 검사는 새 대본 기준으로 갱신했으며 경영·슬롯·UI 동작 검사는 유지했다.

브라우저에서는 새 로컬 저장으로 시작한 오프닝, 타키→아논 등장, 엔터 진행, 대화 기록 열기/돌아가기, 새로고침 후 같은 문장 이어읽기, 375×812의 대사 줄바꿈/가로 넘침 없음을 확인했다. 기존 사용자의 다른 로컬/배포 사이트 저장은 검수 중 초기화하지 않았다. 110개 전체 장면은 자동 검사로 진행했으며 모두를 브라우저에서 수동 감상한 것은 아니다. 새 효과음이나 새 음성을 제작하지 않았고 음질 청취 검수는 수행하지 않았다.
