# PROJECT RiNG v53 — 검수 반영 기록

2026-11-18. `RiNG_v52_5day_review.md`와 `RiNG_v52_Full_Technical_Audit.md`를 바탕으로 저장·자산·조작 동선·릴리스 검증을 우선 개선했다. 검수 문서의 제안 전체를 출시 승인으로 해석하지 않는다.

## 플레이에서 달라지는 점

- 자동 저장, 5개 슬롯, 파일 가져오기를 같은 판독기로 검사한다. 회계 누락·잘못된 시간/가격·중복 주문 ID·대상 없는 작업 등을 거절한다. 이전 버전에서 없던 필드만 이행하며 명시적으로 손상된 값을 정상처럼 채우지 않는다.
- 손상된 자동 저장은 원문을 덮어쓰지 않는다. 이전 정상 저장이 있으면 복구 버튼을 제공하며 손상 원문도 별도 보존한다. 저장 중·완료·실패와 다른 탭의 변경을 알린다.
- 첫 VN 이미지 6개를 우선 준비하고 첫 영업 묶음 4개는 이어서 준비한다. 카메오 전부를 미리 디코딩하지 않는다. 요청별 제한 시간, 준비 취소, 실패 자산의 실제 재요청과 PNG 대체 경로가 있다.
- 음악 버튼을 헤더로 이동했다. 모바일에 남아 있던 숨김 규칙도 해제했다. 영업 중 현재 업무 버튼으로 자동화 설정을 바로 연다.
- 발주 화면의 ‘준비 완료 · 문 열기’로 개점한다. 미결제 수량이 있으면 결제 또는 수량 초기화를 안내하며 자동 결제하지 않는다.
- 설정에서 문제 신고용 진단 JSON을 내려받는다. 빌드 ID·브라우저·정해진 액션/오류 코드·실패 자산만 담고 개인 별칭·전체 저장·대사·임의 오류 메시지는 넣지 않는다. 원격 수집은 없다.

## 자산과 대본

원본 PNG 42개는 보존했다. 기본 배포 파생본은 57,495,665 → 4,735,400바이트이며 배경의 작은 화면용 파생본도 제공한다. 타이틀·프로필·첫 VN·첫 영업에 쓰는 이미지 집합의 manifest 합계는 1,934,102바이트다. 전체 전송량·MP3·HTTP 헤더·캐시·실기기 로딩 시간은 이 수치에 포함되지 않는다.

캐시에 유지하는 이미지 참조는 최대 10개/계산상 RGBA 24MiB로 제한한다. 표시 DOM은 캐시가 소유한 노드를 가져다 쓰지 않는다. 이 상한은 브라우저 디코더·GPU 전체 메모리 측정치가 아니다.

기존 Gemini 대본의 본문·등장 조건·선택지·보상을 유지했다. 표정·속마음은 명시 메타데이터, 저장 위치는 beat ID, 영업 문구는 의미를 가진 ID와 매개변수로 분리했다. 문장 정규식으로 연출을 추정하거나 문장 전체를 번역 키처럼 치환하던 경로를 줄였다. 기존 숫자 커서 저장도 읽는다. v52의 과격한 표현에 대한 주관적 감수 의견은 대본 승인과 별도로 남겨 두었다.

## 검증 범위

`npm test`: 문법·VM·엔진·자산 계약 검사 94개. 시각 관련 이름이 붙은 일부 검사는 소스/모의 DOM 검사이며 실제 화면 캡처와 구분한다. 과거 스냅샷 해시 검사와 개발 검사를 분리했다.

빌드는 같은 소스로 두 경로에서 실행해 동일한 build ID를 확인했다. manifest는 배포 파일별 길이·SHA256, JS/CSS 순서와 이미지 예산을 기록한다. 원본 `app/`을 수정한 뒤 `npm run build`로 `dist/`를 생성한다.

실제 브라우저에서는 타이틀→VN→첫 제조/전달→업무 설정, 슬롯 저장/새로고침/복원, 미결제 발주 보호→결제→개점, 모바일 음악·스토리 탭을 확인했다. 자동 브라우저 결과와 게시 정보는 `V53-RELEASE.json`에 별도로 기록한다.

미확인: 저사양 실기기·저속망 수용 기준, INP/p95 저장 지연, 30분 메모리 추세, 실제 화면 낭독기, 모든 대사의 원작 말투/재미, 저작권자의 허락. 이번 패치가 전체 상업 출시 승인이라는 뜻은 아니다.

## 복원

GitHub의 `v47`, `v52` 복원 지점은 유지한다. `v53` 태그의 `app/`, `dist/`, `backup-v53.json`으로 소스와 배포 artifact를 확인할 수 있다. 개인 저장은 저장소에 포함하지 않는다. 사이트 버전 되돌리기와 브라우저 개인 저장 복원은 별개다.
